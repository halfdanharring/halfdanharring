# Halfdan Harring

Jeg hedder Halfdan Harring, og jeg er fullstack-udvikler fra Aarhus.

Jeg bygger apps, webapps, SaaS-produkter og digitale værktøjer med teknologier som React, TypeScript, Vite, Firebase, Firestore, Capacitor og AI-assisteret udvikling.

Jeg bruger denne GitHub-profil til at arbejde med og dokumentere mine projekter inden for appudvikling, webudvikling, SaaS-produkter og moderne softwareudvikling.

English: I’m a full-stack developer from Aarhus, Denmark, building apps, SaaS products and web tools.

## Hvad jeg arbejder med

- Fullstack-webudvikling
- React, TypeScript og Vite
- Firebase, Firestore og Cloud Functions
- Mobile apps med Capacitor
- SaaS-produkter og MVP’er
- AI-assisteret udvikling med Cursor og ChatGPT
- Produktdesign, UX og konverteringsfokuserede websites
